## 📝 Projektbeschreibung

Dieses Portfolio ist eine vollständig modulare, mehrsprachige Webpräsentation mit dynamischem Content, der über JavaScript aus JSON-Dateien geladen wird. Ziel ist es, meine berufliche Entwicklung, Fähigkeiten und Projekte modern, klar strukturiert und technisch sauber darzustellen.

### Kernmerkmale der Website

* **Dynamische Navigation:** Komplett per JavaScript generiert, mit responsivem Hamburger-Menü und Sticky-Header.
* **Mehrsprachigkeit:** Alle Texte (About, Skills, CV, Stories, Kontakt) werden über ein zentrales `i18n`-System aus JSON-Dateien geladen.
* **Story-/Projekt-Overlays:** Saubere Trennung von Card-Ansicht und Overlay-Ansicht, inklusive Close-Button, ohne Scroll-Bugs.
* **Kontaktformular:** Programmgesteuert erzeugt, mit Labels, Placeholders und Texten aus `ui.json`.
* **Modale Fenster:** Impressum und Datenschutz als JavaScript-generierte Modals.
* **Klares CSS-Konzept:** Jede Komponente ist modular und wartbar aufgebaut.

### Nutzen des Portfolios

* Präsentation meiner **Karriere**, **technischen Fähigkeiten** und **Projekte**.
* Ausrichtung auf Rollen wie **Test Automation Engineer**, **Software Tester**, **SDET**, **QA Automation Specialist**.
* Flexible Erweiterbarkeit für weitere Projekte, Kurse oder Zertifizierungen.
